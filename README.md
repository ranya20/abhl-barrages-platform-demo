# Dam Management Platform

Full-stack dam monitoring and water resources management platform developed as part of an engineering internship project.

## Technologies

- React / Vite
- FastAPI / Python
- PostgreSQL
- Data visualization
- Hydraulic calculations
- Versioned rating curves
- Secure NL-to-SQL data assistant
- Excel/PDF reporting architecture

## Public demonstration

This repository is a sanitized portfolio version of the project.

No internal datasets, credentials, database backups, confidential documents or operational files are included.

Demo screenshots are available in the `demo` directory.

## Architecture

Frontend -> React

Backend -> FastAPI

Database -> PostgreSQL

Data assistant -> secured NL-to-SQL architecture
